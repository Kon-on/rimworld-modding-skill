# 模板字段核验结果

核验对象：library 02-模板 下全部 markdown 里的 xml 代码块（共 39 个文件，成功解析 37 个 XML 块）。

事实来源：docs/def-schema.json —— 由脚本直接读取游戏本体 Data\<资料片>\Defs 的 1,560 个 XML 提取，覆盖 254 种 Def 类型、13,329 条字段路径。

判定规则：

- 已证实：该 XML 元素路径在同名 Def 类型的原版全量字段表里存在（原版确实这么写）。
- 待验证：该路径在本体任何 Def 类型里都不存在——可能是 1.7 新增字段、自定义 Def 类字段、或模板写错。
- 待验证(路径属于其它Def类型)：路径本身在原版存在，但不在该类型下，常见于 li 容器的同名子元素。
- 自定义：位于 Class=ExampleMod.* 的自定义组件子树内，本体无从比对（这是模板故意留的自定义位）。
