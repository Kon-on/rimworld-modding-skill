# RimWorld 1.7 全量 Def 字段索引

覆盖本机 RimWorld **1.7.4981 rev136** 的 `Data/<资料片>/Defs` 下实测出现的 **254 种 Def 类型**、**1560 个 XML 文件**、**14070 个 Def 实例**、**13329 条字段路径**。

每个类型一个文件：`字段/<DefType>.md`（含最小真实范例、核心字段、全量字段表、defName 一览）。
机器可读版本：`字段总表.csv`。

> 「出现率」= 该字段在该类型原版实例中的出现比例，可作「是否必填」的经验判据：≥90% 基本必填；40–90% 常见可选；<10% 属于特例用法。

## 大小写同名冲突

原版 XML 里存在仅大小写不同的 Def 标签，Windows 无法用同一个文件名保存，故后者追加 `_variant`：

- BackstoryDef（845 实例）→ `BackstoryDef.md`、BackStoryDef（1 实例）→ `BackStoryDef_variant.md`
- JobDef（321 实例）→ `JobDef.md`、jobDef（6 实例）→ `jobDef_variant.md`
